# Security

## Reporting a vulnerability

Please report it privately: open this repository's **Security** tab and choose
**Report a vulnerability**
([direct link](https://github.com/takwerx/atak-terminal/security/advisories/new)).
Do not open a public issue, and do not post details, logs or proof-of-concept
data where others can read them.

## Supported versions

Only the latest release gets security fixes. Run `takwerx update` before reporting.

## What to expect

We acknowledge a report within 3 working days, tell you whether we can
reproduce it, and keep you updated until a fix ships. Confirmed issues are
fixed in a new release and credited to you if you want.

## Scope

The installer, the `takwerx` command and the tools it downloads and runs on your computer, including what it writes outside `~/.takwerx` (Windows: `%LOCALAPPDATA%\takwerx`) and what it fetches over the network. Vulnerabilities in ATAK itself belong with the TAK Product Center at tak.gov.
